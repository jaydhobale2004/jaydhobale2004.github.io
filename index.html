Mongo Doctor

Slow MongoDB queries are hard to diagnose, and a wrong index can make things worse. Mongo Doctor scans a database, explains what's wrong in plain language, applies a fix, and measures the query again so you can see whether it actually helped. Every change can be undone.

Role
Solo: design, backend, CLI
Stack
Node.js, Express, MongoDB, Docker, NVIDIA-hosted LLM
When
October 2026
Proof
25 unit tests, CI gate, explain() before/after

Sample database. Figures are illustrative, from the demo dataset.

1Full collection scan

No index matches the filter and sort, so MongoDB reads 1.2M documents to return 42.

Suggest a compound index on { status, createdAt }.

2Unindexed $lookup

The join runs a scan on customers once per order, so cost grows with both collections.

Index the foreign field the join reads.

3Redundant index

A prefix of another index. It costs storage and slows every write while adding no read benefit.

Drop it, keeping a one-click undo.

Autonomous Courtroom

One LLM answering a legal question will sound confident whether it is right or not. This pipeline makes separate agents argue for and against, checks for contradictions in the sources, and only then lets a judge agent rule, with a confidence score attached.

Role
Solo: agent design, data, UI
Stack
Python, RAG, NVIDIA NIM (Llama 3.1 70B), SQLite, Streamlit
Data
Live from India Code and US GovInfo APIs
When
April 2026

How a case moves through the agents

Prosecution and defence work from the same retrieved sources, so neither side can invent its own facts.

AgentRetrievalFinds the relevant sections (RAG)
AgentContradictionFlags sources that disagree
AgentProsecutionStrongest case for
AgentDefenceStrongest case against
AgentJudgeWeighs both, cites sources
OutputRuling + confidenceStored in SQLite, shown in Streamlit

1Identifiers masked before training

Names and other identifiers are replaced with tokens, so the model never learns from them.

Clinical terms like "tightness" split into known pieces, which keeps the model small without losing medical vocabulary.
